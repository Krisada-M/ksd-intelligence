# ADR 0005 — Node >= 22.5 is the package floor

**Status:** accepted 2026-11-12 (owner review of M2a.1). **Context:** the package declared `engines.node: ">=20"` and `@types/node ^20`, carried over from M0. The M2a store is `node:sqlite` (D46), which does not exist on Node 20: it ships from Node 22.5 (behind `--experimental-sqlite` until 22.13 / 23.4) and in Bun. The engine runtime rule (D45) already required Node >= 22.5 or OMP's Bun, but the CLI (`ei index`, `ei status`) and the OMP adapter read the published index in their own process, so a Node 20 host could not open it at all.

## Decision

1. `package.json#engines.node` is `">=22.5"`.
2. `@types/node` moves to `^22`, whose `node:sqlite` declarations cover what `src/storage/` uses; the hand-written `src/storage/node-sqlite.d.ts` is deleted.
3. The engine child still chooses Node >= 22.5 from `PATH`, else OMP's Bun (D45); on 22.5–22.12 and 23.0–23.3 it passes `--experimental-sqlite`.

## Consequences

- Node 20 is no longer a supported host for any `ei` command; CI already runs Node 24 on macOS and Linux (M1d).
- `src/policy/package.json` keeps its own `">=20"`: the KSD module is a frozen contract (DESIGN §6.7) and needs no SQLite.
- Supersedes the M1d brief's note that the package entry stays at Node >= 20.
