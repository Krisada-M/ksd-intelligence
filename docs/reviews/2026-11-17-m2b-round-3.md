## W1 — blocker: a wrong `low` on this repository

Live output, macOS:

```text
IMPACT Graph.incoming — src/core/graph/graph.ts:44
ACTION proceed · level low · picture complete
Callers: none
Tests: none
— index fresh · 372 files · limits: 1 unbounded dynamic import, 175 excluded files
```

`Graph.incoming` is called in `tests/core/indexing.test.ts` (lines 24, 60, 72, 117, 118, 132) and `tests/core/differential.test.ts:253`. The answer says `proceed`, `complete` and `Tests: none`. All three are false.

Cause, two layers:

1. **`ei init` default scope.** `detectProjectLayout` proposes `include: ["src/**"]` when a repository has `src/` and no `packages/` or `apps/`. Tests outside `src/` are then outside the index scope, although `tests/tsconfig.json` owns them. This is the most common layout for a single-package TypeScript repository, so the owner's own projects are likely to hit it.
2. **D55 item 3.** Files outside the scope became a repository limit, shown in the footer only. The lexical name scan covers orphan files (no tsconfig) but not files outside `include`. So nothing in the result points at the callers.

The design reviewer made both decisions (`ei init` defaults in PR #9, D55). The fix is in D57.
