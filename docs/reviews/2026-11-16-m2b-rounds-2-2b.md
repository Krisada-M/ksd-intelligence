## Checked and found sound

- Verdict derivation matches golden P1; factors match P2 as written (`many-callers` on `reach.total`, factors over every impacted symbol). With closure traversal this makes `medium` the common level (47% of the sample); that is the confirmed policy, and the `manyCallers` threshold is an open dogfood question (DESIGN §16).
- Reach uses compiler-grade edges only; heuristic interface callers are listed, not counted.
- Unknown gap codes fall into the repository-wide bucket rather than vanishing.
- A stale answer can only be `unknown`; a schema mismatch never reads the old index as current.
- One build per session at a time; a `busy` lock waits for the other session's publish instead of starting a second build.
- The 20 audited results: no reference to a target missing from its result.
