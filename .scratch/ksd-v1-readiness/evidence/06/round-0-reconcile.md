## 2. Data Assumed by the Brief vs Current SQLite Schema (`SCHEMA_VERSION = 4`)

- `declarations` (`sqlite.ts:62–73`) currently stores `(id, file, name, simple, kind, exported, start_line, end_line, other_spans, sig_hash)` — it does **not** store signature text, doc comment text, split identifier segments, owner tokens, or path tokens.
- `edges` (`sqlite.ts:76–83`) and `edges_target_covering` (`sqlite.ts:139`) **already** provide fast incoming caller counts (`COUNT(DISTINCT source)` per `target`, excluding `TESTS`/`IMPORTS` or filtering to symbol caller edges as appropriate in Round 2).
- `declarations_fts` (added in Schema `5`) is therefore the only schema addition needed for M6a.
